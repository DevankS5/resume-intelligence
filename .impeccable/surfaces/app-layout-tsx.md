# Surface: HR app shell (all routes)

Scope: Operate mode. HR reviewers screen 47+ resumes against two roles. Code-led build.

## Direction contract

THESIS: Screening as a public count, not a leaderboard. Every record is accounted for like ballots in a counting hall; refuses the category default of a grey SaaS dashboard with score donuts.

OWN-WORLD: White form stock with faint slate-blue ruled grid; slate/ink-navy shell rail; indelible-ink violet only for human-verified marks and focus; result-sheet tables with tabular numerals; seal-like round status marks with text labels; soft rounded corners (card/control/chip tokens), never pills.

STORY: HR sees the count reconciles (47 accounted), opens one role's result sheet, reads criteria as rounds and the total last, opens a candidate, checks each point against a quoted passage, marks it in violet ink.

FIRST VIEWPORT: Left slate rail (Overview, LCA Consultant, UI/UX Intern, All records, Upload, Methodology). Top: the ballot-account strip (Expected 47 · Scored · Needs review · Failed) with a proportional segmented bar. Below: two role result cards side by side with top-5 rows each; primary action "Open LCA ranking".

FORM: Counting Hall (Form 20 round-wise result sheet), candidate 6 of 7. seed:57c4614c6b1ef46b. Raises: chrome deleted so type carries structure (metro tiles); reviewer layer never edits machine assessment (orienteering map); states stamp, nothing disappears (ticket wallet); one fixed 0–100 scale across rows (botanical folio).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
